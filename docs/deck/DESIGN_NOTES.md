# Design brief: reference intro slide (g3f5209d8ff1_287_13659), partial read

Read via Slides API (slide 2 layout, text styling and master). Applied to v2: reference master ('Databricks Theme: Light'), title-slide layout for cover and presenter line, title-only layout for content slides.

1. White page background, DM Sans throughout (Databricks type family), left-aligned on one margin.
2. Title is a bottom-anchored CENTERED_TITLE block with a 41pt dark line over a 48pt Databricks-red (#FF3621) bold accent line.
3. Title block sits in the lower-middle of the slide, leaving large empty space above it (no clutter).
4. Presenter block is a separate SUBTITLE placeholder below the title: name in bold, then date/role, 11pt spacing above.
5. Only two text elements on the slide: one headline and one presenter line. No decorative imagery needed.
6. Speaker notes carry the detail (bulleted premise, purpose, shift) and the slide stays sparse.
7. Hierarchy comes from size and colour contrast (dark title, red accent, smaller presenter line), not from boxes or borders.
8. Use the reference layout on the master so fonts, colours and placeholders are inherited, not hand-set per slide.
9. Keep line spacing near 90% on titles so two-line headlines stay tight.
10. Apply the same grid to every slide: consistent title position and size, footer label bottom-left, generous margins.

# Evidence index: FE Bar medical-necessity appeals build

> **Start here:** [`00_LIFECYCLE.md`](00_LIFECYCLE.md) maps the evidence to the engineering lifecycle — design → build → test → validate → deploy — plus the enhancements driven by testing.

Every artifact below is text committed in this repo. No screenshots are used as evidence. Every figure is the current state, verified on 2026-11-26 (UTC) unless a row gives another date.

**How to read the labels**
- **REAL**: executed on the Databricks workspace `fevm-appeals-hackathon` (or a local test run, where stated).
- **SYNTHETIC data**: every patient, claim, note, member ID, facility and eval label is generated by `generator/` (seed `20261124`). Nothing comes from a live customer system.
- **SIMULATED**: reviewer actions (recorded as `demo-reviewer (simulated)`) and the payer submission, which is not implemented.

**Number sources.** `docs/business_case/DECK_NUMBERS.md` is the only source for $ figures. Prototype metrics come from the files named in its section 6.

Stage key: **Lakeflow** (SDP and Jobs), **UC** (Unity Catalog governance), **Lakebase**, **ML/GenAI** (generation, chat, eval), **Genie Agent**, **App** (Databricks App), **Biz** (business case), **Build** (tests and code review).

## 3. What is real and what is simulated

**Real**
- Every Databricks run: SDP update, job run, grounding, generation, eval, Lakebase sync, Genie benchmarks, app API calls, chat endpoint, billing query.
- LLM output: `databricks-claude-sonnet-4-6` through `ai_query`, on synthetic inputs.
- Local pytest runs for the generator, the parser and the app.

**Simulated**
- All patients, claims, notes, facilities, member IDs and labels (`generator/`, seed `20261124`).
- Reviewer actions (`demo-reviewer (simulated)`), including the hero's APPROVE and SUBMIT. `SUBMIT` is a status in the app, not a payer submission.
- `review_state_uc` is a simulated copy of reviewer state. Genie answers about approval rate use simulated actions.
- Payer submission: not implemented.
- Payer contract terms: not reviewed. Each data sheet says so.

**Ground truth.** Accuracy (#10) compares the model with the generator's designed label. It is not a payer overturn rate and not a clinical outcome.
